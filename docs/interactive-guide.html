1  Agent pipeline — who does what

Click any card to expand. Every LLM-consuming agent is driven by an editable prompt in prompts/.

AGENT 1   Investigation Agent  agents/investigation_agent.py

Investigates each message: regex IOC extraction -> URL analysis -> LLM verdict (is_scam / confidence / threat_type / summary) -> validation -> RiskEngine score. Returns a validated InvestigationResult.

Prompt file: prompts/investigation_prompt.txt

AGENT 2   Adaptive Investigation Engine  tools/adaptive_investigation_engine.py

Deterministic 'strategy brain'. Picks the victim persona (language / style / digital literacy) from the threat family and walks an objective ladder. No LLM calls - fully unit-testable.

Prompt file: n/a (rule-based code)

AGENT 3   Conversation Agent  agents/conversation_agent.py

Writes the persona's next chat reply. Stays in character, pursues the engine's current objective, replies in the scammer's language, < 35 words, never breaks cover.

Prompt file: prompts/conversation_prompt.txt

AGENT 4   Report Agent  agents/report_agent.py

Compiles verdict + IOCs + risk + honeypot dialogue into a professional markdown incident report (executive summary, risk assessment, recommendations...).

Prompt file: prompts/report_prompt.txt

Deterministic support tools (no LLM → free, fast, testable)

4  Objective ladder — the persona's state machine

Every engine.update(objective_completed=True) archives the current objective and activates the next one. Simulate a full investigation:

turn 1
  1. 1. Collect official verification website → strategy Curious
  2. 2. Collect employee ID → strategy Confused
  3. 3. Collect payment method → strategy Cooperative
  4. 4. Keep conversation on chat → strategy Busy
  5. 5. Waste scammer time → strategy Skeptical
  6. 6. End investigation → strategy Cautious
🎉 All objectives completed — engine would answer "End investigation" and stay there (no loops).

8  Glossary

TermMeaning in TraceAI
IOCIndicator of Compromise - a concrete artifact (URL, phone, UPI ID...) that links a message to scam infrastructure.
HoneypotA decoy system used to attract and study attackers. Here: the persona chat channel that keeps the scammer talking.
Decoy personaA fake victim identity (name, occupation, language...) generated to match the scam type.
Objective ladderThe ordered list of extraction goals the engine walks through (website → employee ID → payment method → stall → end).
Risk score0-100 composite of LLM verdict + confidence + IOC signals, with written reasons for every point.
SessionOne multi-turn undercover conversation, keyed by session_id, kept alive in memory by the API.
Threat memoryThe JSON archive of finished investigations (database/threat_memory.json).
